\title{Target-Conditioned Cognitive Evidence Retrieval for Inductive Knowledge Tracing over Unseen Concepts}
\author{}
\date{}

\begin{document}
\maketitle

\begin{abstract}
Online learning platforms continually introduce new questions and knowledge concepts. As a result, evaluation targets may involve concepts unseen during training, leaving knowledge tracing models that rely on question or concept identifiers without direct supervision signals. We propose Cognitive-RAG KT, which retrieves transferable evidence from a student's pre-target history using the target question as the query. The model builds a hierarchical evidence context from question semantics, knowledge structure and collaborative behavior, and uses a structured evidence summary to compress mastered concepts, weak concepts, transfer state and evidence quality. The student-side evidence context, summary-derived features and target-question prior are mapped into soft slots, injected into a frozen LLM, and used to compute the probability of a correct response from label logits. Experiments on MOOCRadar, XES3G5M and FoundationalASSIST show that Cognitive-RAG KT outperforms multiple KT baselines. Slice analysis and ablations further show that target-conditioned evidence retrieval provides the most stable gain in probability ranking, while structured evidence and structured evidence summaries provide complementary support.
\end{abstract}

\noindent Keywords: knowledge tracing; unseen-concept knowledge tracing; target-conditioned evidence retrieval; structured evidence summary; frozen LLM

\section{Introduction}

Knowledge tracing (KT) estimates a student's knowledge state from prior learning interactions and predicts performance on later questions or learning activities. As a core capability of intelligent education systems, KT supports personalized practice recommendation, learning path planning and instructional intervention. Real platforms, however, do not keep their question banks, course content or knowledge organization fixed. New questions and knowledge concepts appear over time, and these concepts may not occur in the supervised interactions used for training. For target questions associated with held-out concepts, a model cannot directly rely on historical labels, question-ID statistics or concept embeddings for those concepts. It must therefore transfer from existing learning experience to held-out concept targets.

Most traditional KT methods use question IDs, knowledge concept IDs or their supervised representations as core inputs. BKT, DKT and DKVMN model student interaction histories through probabilistic graphs, recurrent networks or memory networks, while SAKT, SAINT and AKT use attention mechanisms to capture interaction dependencies\citep{corbett1995knowledge,piech2015deep,zhang2017dynamic,pandey2019sakt,choi2020saint,ghosh2020akt}. These methods can learn student states effectively when training and test data share the same question or concept distribution. When a test target involves a held-out concept, however, discrete identifiers and their parameterized representations have no direct learning basis. Recent work uses question text, concept semantics and structural relations to mitigate this problem\citep{fu2024sinkt}, but a finer question remains unresolved: for the same held-out concept target, which interactions in each student's history are truly transferable.

Unseen-concept prediction cannot be solved by simply extending the history length. A student's history contains prerequisite support, semantic neighbors and structural relations that are closely related to the current target, but it also contains weakly related or redundant information. The same historical interaction may have different transfer value for different held-out targets. The central issue is therefore not how to feed more history into the model, but how to identify which pre-target interactions provide transferable evidence for the current held-out concept target.

To address this issue, we propose Cognitive-RAG KT. The model uses the current unseen-concept target question as the query, performs target-conditioned evidence retrieval over the student's pre-target history, and builds a hierarchical evidence context from question semantics, knowledge concepts, cognitive attributes, knowledge structure and collaborative behavioral relations. A structured evidence summary then compresses the retrieved evidence into constrained fields, including mastered concepts, weak concepts, transfer state, risk level and evidence quality. The student-side evidence context, summary-derived features and target-side prior are mapped into continuous soft slots, injected into the representation space of a frozen LLM, and used to compute the probability of a correct response through a binary softmax over label logits.

This design adapts retrieval augmentation to target-conditioned evidence selection for cross-concept transfer. The full history is organized as structured evidence rather than rewritten as a natural-language prompt, and the LLM is used for label-logit prediction rather than free-form judgment. Experiments on three public datasets show stable gains. Ablation analysis further shows that target-conditioned evidence retrieval is the largest contributor to probability ranking, structured evidence provides secondary support, and structured evidence summaries provide an auxiliary compression gain.

Our contributions are fourfold. First, we formulate an unseen-concept knowledge tracing protocol in which every test target contains at least one concept absent from training supervision. Second, we introduce target-conditioned evidence retrieval, which selects transferable interactions from a student's pre-target history and organizes them with question semantics, knowledge structure and collaborative behavioral relations. Third, we design a frozen-LLM soft-slot predictor that maps student-side evidence, summary-derived features and target-side priors into continuous inputs and estimates the correct-response probability from label logits. Fourth, we evaluate Cognitive-RAG KT on MOOCRadar~\citep{yu2023moocradar}, XES3G5M~\citep{liu2023xes3g5m} and FoundationalASSIST~\citep{worden2026foundationalassist}, comparing it with representative KT baselines and analyzing retrieval controls and key-component ablations.

\section{Related Work}

\subsection{Traditional Knowledge Tracing and Unseen Knowledge Concept Prediction}

Knowledge tracing (KT) estimates a student's knowledge state from historical learning behavior and predicts performance on subsequent questions. Early models, including BKT, item response theory and cognitive diagnosis models, describe student states through explicit skills, item parameters or latent variables\citep{corbett1995knowledge,chen2021irt,pavlik2009pfa,tatsuoka1983rulespace}. Later, DKT and DKVMN learn temporal dependencies with recurrent or memory structures, while SAKT, SAINT and AKT use attention mechanisms to model long-range interaction relations\citep{piech2015deep,zhang2017dynamic,pandey2019sakt,choi2020saint,ghosh2020akt}. These models are strong when training and test data share questions, concepts and supervised distributions, but their learned question or concept representations provide little direct support when a target involves held-out concepts.

Semantic-enhanced KT addresses part of this gap by using question text, concept semantics and question-concept structure to improve representation under concept shift\citep{fu2024sinkt}. Such information helps describe held-out targets, but it does not by itself decide which interactions in a particular student's pre-target history are transferable to the current target. Unseen-concept knowledge tracing therefore requires both target representation and target-conditioned evidence selection.

This distinction matters because the same held-out concept may require different historical support for different students, and different held-out targets for the same student may activate different learning fragments. Although attention-based KT models can highlight parts of a history, the weighting is usually implicit and does not specify the evidence role of each selected interaction. Our method focuses on target-conditioned individualized evidence selection under the constraint that target concepts lack training-stage supervision.

We use the term unseen-concept knowledge tracing for this inductive setting, where every test target contains at least one concept unseen during training. This setting is distinct from new-student cold start and new-question cold start.

\subsection{Retrieval Augmentation and Individualized Evidence Modeling}

Retrieval-Augmented Generation (RAG) selects evidence according to a query and uses that evidence to supplement or constrain subsequent inference. The framework proposed by Lewis et al. combines a parametric language model with non-parametric external memory and retrieves relevant text before answer generation, improving information access in knowledge-intensive tasks\citep{lewis2020rag}. Later work further shows that retrievers, rerankers, context selection and evidence organization jointly affect the reliability of language-model outputs.

In education, retrieval augmentation has been used for course question answering, learning resource recommendation, automatic feedback generation and knowledge-base access\citep{li2025ragedusurvey,swacha2025ragchatbots,dong2023kgrag,zheng2024edukdqa}. These studies show that retrieval can anchor model outputs in inspectable external evidence. KT imposes a different target: the model must output a probability for a student's response to the current question under a strict historical information boundary. Retrieval for KT should therefore operate over the student's pre-target history, where the query is the target question and the candidates are prior interactions.

For unseen-concept prediction, retrieval also supports cross-concept transfer. Question text, concept semantics, cognitive attributes, knowledge structure and collaborative behavioral relations are used to assess transfer relations between candidate history and the current target. The retrieval output is a structured evidence set with support direction, evidence role, relative position and relation source, allowing the probability judgment to be traced back to concrete learning experiences.

\subsection{Reasoning Potential of Large Language Models and Their Constrained Use in KT}

Large language models show strong potential in text understanding, semantic association and conditional inference, and have been used in educational question answering, learning resource generation, personalized feedback and learning analytics\citep{kasneci2023chatgpt,cho2024systematic}. For held-out concepts, question text and concept descriptions provide semantic entry points for understanding target ability requirements. The methodological question is how to use this representation capacity without turning KT into free-form prompting or explanation generation.

Existing LLM-enhanced KT methods use language models to encode question and concept semantics, or use instruction alignment and contextual representations to support next-question prediction\citep{fu2024sinkt,wang2025llmkt}. These studies provide a basis for concept generalization, but general language knowledge is not the same as an individual student's knowledge state. Prediction through direct prompting or free-form generation also makes the output depend on prompt format, external commonsense, generation randomness and post-processing rules.

We use the LLM as a frozen conditional representation and label-discrimination space. Target-conditioned evidence retrieval provides traceable student evidence for the current target, the structured evidence summary compresses this evidence into constrained fields, and final prediction is computed only from label logits. Student-side evidence, summary-derived features and target-side priors are mapped into continuous soft slots and fed into the model with a label-constrained prompt. This design keeps the prediction grounded in structured student evidence while using the LLM for conditional discrimination.

In summary, Cognitive-RAG KT keeps KT as the core prediction task and uses retrieval augmentation to transform experience on existing concepts into transferable evidence for held-out concept targets. A hierarchical evidence context and structured evidence summary form the student-side conditional representation, soft slots inject this representation into a frozen LLM, and label logits provide the final probability. Retrieval defines the evidence boundary, the context and summary provide encodable student-side representations, and the frozen LLM supplies a constrained conditional discrimination space.

\section{Method}

\subsection{Research Problem, Information Boundary and Overall Framework}

\subsubsection{Inductive Prediction over Unseen Knowledge Concepts}

Let \(\mathcal{U}\), \(\mathcal{Q}\) and \(\mathcal{C}\) denote the sets of students, questions and knowledge concepts. For any student \(u\in\mathcal{U}\), the learning process is an interaction sequence ordered by time:
\[
S_u=\{(q_{u,1},y_{u,1}),(q_{u,2},y_{u,2}),\ldots,(q_{u,T_u},y_{u,T_u})\}
\]

Here, \(q_{u,i}\in\mathcal{Q}\) denotes the question answered by student \(u\) at the \(i\)-th interaction, and \(y_{u,i}\in\{0,1\}\) denotes the response outcome. At prediction position \(t\), the question to be predicted is the target question \(q_{u,t}\). The model can use only the interactions that occur before this target:
\[
H_{u,<t}=\{(q_{u,i},y_{u,i})\mid 1\leq i<t\}
\]

We define KT prediction as the following conditional probability estimation problem:
\[
p_{u,t}=P(y_{u,t}=1\mid H_{u,<t},q_{u,t})
\]

The variable \(p_{u,t}\) denotes the theoretical target probability that student \(u\) answers target question \(q_{u,t}\) correctly, and \(\hat{p}_{u,t}\) denotes the model estimate of that probability. During training, the true label \(y_{u,t}\) is used only to compute the supervised loss. During prediction, the target label is not included in the model input.

For unseen-concept targets, prediction also depends on attributes \(a(q_{u,t})\) that are available before the response. These attributes include question text, manually annotated concepts, cognitive level and static relational features. The multi-source prior module later refines the general conditional probability into \(P(y_{u,t}=1\mid H_{u,<t},q_{u,t},a(q_{u,t}))\).

To define the evaluation boundary for unseen-concept knowledge tracing, let \(\mathcal{C}_{\mathrm{tr}}\) denote the concepts observed in supervised training interactions, and let \(\mathcal{C}_{\mathrm{u}}\) denote the held-out concepts that are absent from training supervision:
\[
\mathcal{C}_{\mathrm{tr}}\cap\mathcal{C}_{\mathrm{u}}=\emptyset .
\]
A test target \(q_{u,t}\) is selected when its associated concept set satisfies \[C(q_{u,t})\cap\mathcal{C}_{\mathrm{u}}\neq\emptyset .\] This target-level construction ensures that each evaluated target involves at least one concept without training-stage supervision. Since educational questions may be annotated with multiple concepts, the selected test targets may also include concepts observed in training. This design preserves naturally multi-concept targets while evaluating whether the model can transfer from pre-target learning history and observable target-question priors to concepts absent from training supervision.

The setting follows the information boundary of KT prediction: only interactions before the target position are available as student history, while the held-out concepts themselves do not provide supervised training labels. When stronger history-filtering variants are considered, they can be analyzed as additional evaluation slices.

For an unseen-concept target, interactions in the student's history are not only temporal events. The same historical record may serve as prerequisite support, a semantic neighbor, homogeneous transfer or structural complement for different targets, or it may be weakly related to the current target. We therefore treat \(H_{u,<t}\) as a candidate set for target-conditioned evidence selection rather than as a target-agnostic fixed state.

\subsubsection{Question Priors and Transferable Evidence Representation}

Under unseen-concept conditions, a question cannot be represented only by a discrete question ID. For any question \(q\), we characterize its target-side prior using attributes available before the response: question text, associated concepts, cognitive level, difficulty attributes, semantic representation, graph-structural relations and collaborative behavioral relations. These attributes specify the knowledge requirements of a target question and support relation scoring between a historical question \(q_{u,i}\) and the current target \(q_{u,t}\).

Question text and manually annotated concepts provide semantic entry points for held-out targets. Cognitive level and question type describe ability requirements. Graph structure and collaborative behavioral relations connect the target with existing concepts and existing questions. Together, these attributes form the multi-source target-side prior.

We distinguish the raw question identifier from the semantic identifier representation. The hierarchical semantic identifier characterizes the question's position in semantic space and is not equivalent to the original question ID. For a historical interaction \((q_{u,i},y_{u,i})\), the interaction is treated as candidate evidence. Each evidence item contains three types of information: the attributes of the historical question, the student's response outcome on that question, and the relation between the historical question and the current target question.

The historical response outcome indicates the student's performance on that question, but its predictive meaning depends on the relation between the historical question and the target. We define the evidence value of a historical interaction as a target-conditioned relational property rather than a static label of the question itself. Each candidate evidence item has an evidence role in the current prediction, such as prerequisite support, homogeneous transfer, semantic neighbor, higher-order transfer, graph-structural complement or collaborative complement.

The role explains why the historical interaction is related to the target question. For example, a correct response on a prerequisite question and a correct response on a loosely related question have different evidence meanings, even if their response labels are identical.

\subsubsection{Pre-Target History and Prediction-Time Information Boundary}

We follow both the pre-target history constraint and the information boundary of unseen-concept knowledge tracing. For a target sample \((u,t,q_{u,t})\), the model can use only the student's history before \(t\), denoted by \(H_{u,<t}\), and the target-question attributes available before the response. The target label \(y_{u,t}\) and future interactions are excluded from model input. The target label is used only to compute the loss during training and metrics during evaluation. This boundary applies to target-conditioned evidence retrieval, evidence-context construction, structured evidence summary generation and soft-slot probability prediction.

Beyond static attributes such as question text, manually annotated concepts and cognitive level, question difficulty, collaborative behavioral relations, knowledge-graph statistics and behavioral embeddings all depend on student response records. These response-derived priors are therefore estimated within the fitting-set boundary and frozen during validation and testing. The label of any validation or test target, future interactions, and labels from validation or test sets are excluded from question-prior construction, evidence selection and model input. For a target question whose response-derived collaborative signal is unavailable within this fitting boundary, the target-side collaborative component is treated as unavailable and is encoded as a zero vector rather than being estimated from validation or test interactions.

The target-conditioned evidence retrieval module first selects historical evidence only from \(H_{u,<t}\); the retrieval target never includes the response outcome of the target question or future interactions. The evidence-context construction module then organizes pre-target historical evidence and its structured relations into a student-side evidence context. The structured evidence summary module compresses only the selected pre-target evidence and its statistical summary. It receives no target label and does not output a final prediction label.

Finally, the frozen-LLM soft-slot probability prediction module receives only the student-side evidence context, structured evidence summary-derived features, the target-side prior and a label-constrained prompt. It outputs the probability of a correct response.

With these definitions, KT becomes a problem of target-conditioned evidence selection and probability prediction. The model input is not a concatenation of the full history, but pre-target evidence selected and organized around the current target question. The model output is not a natural-language explanation or open-ended answer, but the predicted probability \(\hat{p}_{u,t}\) of a correct response. This definition provides a unified basis for multi-source question-prior modeling, target-conditioned evidence retrieval, evidence-context construction, structured evidence summary generation and soft-slot probability prediction.

\subsubsection{Overall Framework for Unseen Knowledge Concepts}

Given a target sample \((u,t,q_{u,t})\), Cognitive-RAG KT takes the pre-target history \(H_{u,<t}\) and the target-question attributes available before the response as input. The model outputs the probability of a correct response, \(\hat{p}_{u,t}\).

When \(C(q_{u,t})\cap\mathcal{C}_{\mathrm{u}}\neq\emptyset\), the model has no supervised interactions for the held-out concept requirements during fitting. The key challenge is therefore not to learn a new discrete identifier for these concepts, but to transform the target-side prior into a transfer interface that connects the target to existing learning experience.

The framework performs five steps: multi-source question-prior modeling, target-conditioned evidence retrieval, evidence-context construction, structured evidence summary generation, and frozen-LLM soft-slot probability prediction. The prior and retrieval modules establish cross-concept relations and select transferable evidence from histories over existing concepts. The context and summary modules organize the selected evidence into a student-side conditional representation, and the prediction module maps this representation and the target prior into continuous soft slots.

\subsection{Multi-Source Question Priors and Target-Conditioned Evidence Retrieval}

\subsubsection{Transferable Multi-Source Question Priors}

The core difficulty of held-out concepts is that discrete question or concept IDs have learnable parameter meaning only in the fitting data, while the IDs of test targets provide no directly reusable supervision signal. We therefore represent each question by observable attributes and fitting-boundary statistics rather than by held-out IDs.

For the question set \(\mathcal{Q}=\{q_1,q_2,\ldots,q_M\}\), each question \(q_j\) is described by its stem text, associated concepts, cognitive attributes and statistical features that can be estimated within the unseen-concept evaluation boundary. This representation provides a common coordinate system for judging, from observable attributes, whether a transferable relation exists between a held-out target and historical questions.

The multi-source question prior \(r_j\) contains semantic, behavioral and structural information for retrieval and prediction. The first component is a text-semantic representation \(s_j\), which maps question text into a semantic vector space and supports content-level relation scoring between historical questions and the target.

The second component is a hierarchical semantic identifier representation \(h_j\). It encodes the position of a question in a semantic hierarchy or question-cluster structure, so retrieval can use both fine-grained neighboring questions and higher-level related questions.

The third component is a cognition-enhanced semantic representation \(c_j\), which integrates question difficulty, ability requirement, question-type structure and knowledge organization. It supports relation scoring when two questions have different surface texts but similar operations or solution structures.

\subsubsection{Difficulty, Cognitive Level and State Features}

Question-side priors describe questions and their relations to other questions, but KT prediction must also account for the student's response state in historical interactions. For the same historical question, correct and incorrect responses convey different evidence directions; for the same response outcome, evidence value also depends on question difficulty, historical position and recent student performance.

We build dynamic student-state features in addition to question priors. Let \(H_{u,<t}\) denote the history of student \(u\) before target question \(q_{u,t}\). For any historical interaction \((q_i,y_i)\) with \(i<t\), the difficulty and cognitive level of \(q_i\) provide question-side background, while \(y_i\) records the student's observed performance. The candidate evidence representation consists of question text semantics, hierarchical semantic identifier, cognition-enhanced semantics, question difficulty, cognitive level, historical response outcome and positional state. This representation provides the input for target-conditioned evidence retrieval.

The state interpretation depends on both response outcome and question attributes. Repeated errors on low-difficulty questions may indicate weakness in foundational concepts, whereas errors on high-difficulty or integrative questions may indicate weakness in higher-order transfer. Historical position and recent response patterns are retained so that retrieval can distinguish long-term background evidence from the student's current state.

\subsubsection{Collaborative and Graph-Structural Priors for Cross-Concept Transfer}

Beyond question text and knowledge attributes, student-group response behavior provides relation information. We construct a collaborative prior from co-occurrence and response patterns inside the fitting boundary. For question \(q_j\), the collaborative representation \(a_j\) describes its relative position in group learning behavior only when such behavior is observable from fitting-set interactions. If \(q_j\) is a held-out target question without a fitting-boundary collaborative signal, \(a_j\) is encoded as a zero vector and is not inferred from validation or test responses. This representation supplements relations that text semantics and knowledge-point labels may fail to cover.

The collaborative prior expands evidence sources beyond text similarity and direct concept overlap. Some questions are not textually similar and may not share the same knowledge-point labels, but student performance on them can be correlated. Such group response patterns provide supplementary transfer relations when they are available inside the fitting boundary.

We also construct graph-structural and concept-relation priors to describe structural links between questions and knowledge concepts. In KT, a question is usually associated with one or more knowledge concepts, and concepts may have co-occurrence, prerequisite, inclusion or adjacency relations. Direct concept overlap alone can miss indirectly related questions.

Question-concept relations and inter-concept structural relations are organized as graph-structural information to obtain the structural representation \(g_j\). This representation complements direct knowledge-point labels and supports retrieval of historical interactions with indirect concept links or structural proximity to the target question.

The question-side information is represented as a structured target-side prior:
\[
r_j=\left(\mathbf e_j^{\mathrm{sem}},\mathbf a_j,\mathcal N_j^{\mathrm{graph}},\mathcal N_j^{\mathrm{collab}},\mu_j,\ell_j\right).
\]

Here, \(\mathbf e_j^{\mathrm{sem}}\) denotes the semantic representation formed jointly by question text, hierarchical semantic identifiers and cognitive attributes. \(\mathbf a_j\) denotes the fitting-boundary group-behavior representation of the question, and is zero-filled when no such signal is available under the information boundary. \(\mathcal N_j^{\mathrm{graph}}\) and \(\mathcal N_j^{\mathrm{collab}}\) denote the knowledge-structure neighborhood and fitting-boundary collaborative-behavior neighborhood. \(\mu_j\) and \(\ell_j\) denote question difficulty and cognitive level.

This structured prior provides the question-side basis for target-conditioned evidence retrieval. By unifying question semantics, knowledge structure, group behavior and cognitive attributes, it assigns an inspectable transfer description to each candidate historical interaction.

The prior does not replace the student's historical sequence. It specifies how a historical interaction may be related to the current target.

The unseen-concept knowledge tracing protocol requires any difficulty, collaborative or graph statistics that depend on response records to be constructed only from interactions over \(\mathcal{C}_{\mathrm{tr}}\). Labels and interactions of held-out concepts must not participate in estimating these statistics. An unseen target question can therefore use its pre-response text, annotations and exogenous structural attributes to locate transfer paths, but it cannot obtain implicit supervision through behavioral statistics of the held-out concept requirements.

\subsubsection{Two-Stage Transfer Evidence Retrieval for Unseen Targets}

For a target question associated with held-out concepts, the student's history contains no fitting-stage supervision that can be directly indexed by the target concept ID. The retrieval module uses the target-question prior as a condition and identifies which interactions on existing concepts can serve as transfer evidence for the target.

Given student \(u\), prediction time \(t\) and target question \(q_{u,t}\), the module selects from the pre-target history \(H_{u,<t}\) an evidence set \(E_{u,t}\) with interpretable relations to \(q_{u,t}\). The target prior determines what to retrieve, while the student's response outcomes on seen concepts determine the support direction.

Let the pre-target history of student \(u\) be
\[
H_{u,<t}=\{(q_1,y_1),(q_2,y_2),\ldots,(q_{t-1},y_{t-1})\}
\]

where \(q_i\) denotes the question in the \(i\)-th historical interaction, and \(y_i\in\{0,1\}\) denotes the student's response outcome. The two-stage evidence retrieval module takes \((u,t,q_{u,t},H_{u,<t})\) as input and outputs the evidence set
\[
E_{u,t}=\{e_{u,t}^{1},e_{u,t}^{2},\ldots,e_{u,t}^{K}\}
\]

where each evidence item \(e_{u,t}^{k}\) corresponds to one historical interaction and its relation to the target question. Unlike ordinary sequence truncation or recent-interaction selection, retrieval is conditioned on the target question, so the same student history can produce different evidence sets for different targets.

For example, a correct response on a basic question can provide prerequisite support when predicting an advanced question on the same knowledge chain, whereas an incorrect response on a semantically close or structurally related question can indicate risk for the current question.

\subsubsection{Candidate Recall}

The first stage forms a candidate set from a limited history window before the target question:
\[
C_{u,t}=\{(q_{u,i},y_{u,i})\mid t-W\leq i<t\}.
\]

For each historical interaction in the candidate set, the model treats knowledge concepts, semantics, cognitive level, collaborative behavior and graph structure as multi-source signals that characterize the relation between the historical question and the target question. The first stage uses these signals to compute a target-relevance score and retains high-scoring candidates, providing a candidate space that covers different relation types for subsequent evidence selection.

\subsubsection{Evidence Reranking}

The second stage evaluates evidence value over the candidate set \(C_{u,t}\). For a candidate evidence item \(e_i=(q_i,y_i)\), its support score with respect to target question \(q_{u,t}\) is defined as
\[
s_{i,t}=\lambda_{\mathrm{k}}s^{\mathrm{k}}_{i,t}+\lambda_{\mathrm{s}}s^{\mathrm{s}}_{i,t}+\lambda_{\mathrm{g}}s^{\mathrm{g}}_{i,t}+\lambda_{\mathrm{c}}s^{\mathrm{c}}_{i,t}+\lambda_{\mathrm{y}}s^{\mathrm{y}}_{i,t}+\lambda_{\mathrm{r}}s^{\mathrm{r}}_{i,t}.
\]

Here, \(s^{\mathrm{k}}_{i,t}\) denotes concept association, \(s^{\mathrm{s}}_{i,t}\) denotes semantic and cognitive-level association, \(s^{\mathrm{g}}_{i,t}\) denotes knowledge-structure association, and \(s^{\mathrm{c}}_{i,t}\) denotes collaborative-behavior association. \(s^{\mathrm{y}}_{i,t}\) denotes the support direction of the historical response outcome for the current prediction, and \(s^{\mathrm{r}}_{i,t}\) denotes the time-decay term.

The coefficients are determined within the fitting set or specified by a unified configuration, and are fixed during testing. For unseen-concept targets, the first four relation terms are computed from the pre-response prior of the target question and the priors of seen historical questions, while \(s^{\mathrm{y}}_{i,t}\) encodes only the student's observed outcome on a historical question. The scoring process never uses the response label of the target concept. The relation terms correspond to prerequisite support, homogeneous transfer, semantic neighbor evidence, higher-order transfer, graph-structural complement and collaborative complement, and the response-state term gives each target-related historical response its positive or risk-indicating direction.

These roles distinguish basic-to-advanced relations, similar-task transfer, text-semantic proximity, cross-level relations, concept-graph links and group-behavior relations. Evidence retrieval is therefore target-conditioned evidence selection for KT prediction, not question-similarity ranking alone.

\subsubsection{Coverage and Redundancy Control}

Selecting top-ranked candidate interactions only by support score can produce repeated roles or highly overlapping semantics. We therefore add coverage and redundancy control to preserve high-support evidence while covering different evidence roles and relation sources, including same-concept relations, semantic neighbors, prerequisite support, graph-structural neighbors and collaborative-behavior relations. If multiple candidates have highly similar semantic representations, the same knowledge concept and the same evidence role, the module preferentially retains interactions with higher support scores, more representative historical positions or more interpretable response states.

Different evidence roles describe student state from different perspectives. Homogeneous transfer emphasizes performance on similar tasks, prerequisite support emphasizes foundational ability, semantic neighbors emphasize expression-level relatedness, graph-structural complement emphasizes concept-structure links, and collaborative complement emphasizes group-behavior relations.

Formally, we construct the final evidence set greedily:
\[
E_{u,t}=\arg\max_{|E|=K}\left[\sum_{e_i\in E}s_{i,t}+\lambda_{\mathrm{cov}}\operatorname{Cov}(E,q_{u,t})-\lambda_{\mathrm{red}}\operatorname{Red}(E)\right],
\]

where \(\operatorname{Cov}(E,q_{u,t})\) measures the coverage of different transfer-relation sources and target ability requirements. \(\operatorname{Red}(E)\) measures semantic, concept and role repetition among evidence items. This constraint retains complementary evidence such as prerequisite support, homogeneous transfer and structural complement under limited capacity. The history-window length \(W\), candidate size and final evidence count \(K\) are reported in the experimental settings.

The target-conditioned evidence retrieval module finally outputs \(E_{u,t}\), where each item contains the historical question, historical response outcome, evidence role, support score, historical position and relation source with the target question. Evidence-context construction organizes this structured evidence set into student-side state and local evidence blocks for frozen-LLM soft-slot probability prediction.

\subsection{Student-Side Evidence Context Construction}

\subsubsection{From Cross-Concept Evidence to Structured Context}

The two-stage retrieval module outputs discrete transfer evidence from histories over existing concepts. The evidence-context module organizes these results into a structured representation containing a global student state, local transfer evidence blocks and a target-question representation.

Given student \(u\), prediction time \(t\), target question \(q_{u,t}\) and retrieved evidence set \(E_{u,t}\), this module produces a student-side evidence-context representation \(x^{ctx}_{u,t}\) and a target-side representation \(x^{tar}_{t}\). The former describes the student's performance, evidence structure and state features in the history over existing concepts. The latter describes the semantics, hierarchy, ability requirements and available relational priors of the current held-out question.

The two representations are not interchangeable. The student-side representation provides observed ability evidence, while the target-side representation specifies the ability requirement to which that evidence should be transferred. The frozen-LLM soft-slot prediction module receives them separately and injects them into context soft slots and target soft slots through projectors.

\subsubsection{Target-Conditioned Global Student State}

The global student state summarizes aggregate trends under the current target question, including recent response performance, risk level, dynamic state and the distribution of major evidence roles. We combine retrieved evidence \(E_{u,t}\) with state information in the student's historical interactions to generate \(G_{u,t}\), which provides global context for local evidence.

Specifically, we aggregate only the retrieved pre-target evidence with target-relevance weights:
\[
{G_{u,t}=\sum_{k=1}^{K}\alpha_{k,t}\left[\mathbf e_{i_k}^{\mathrm{sem}};y_{u,i_k};\boldsymbol{\rho}_{i_k,t};\delta_{i_k,t}\right],\qquad \alpha_{k,t}=\frac{\exp(s_{i_k,t})}{\sum_{j=1}^{K}\exp(s_{i_j,t})},}
\]

Here, \(i_k\) denotes the original position of the \(k\)-th retrieved evidence item in the pre-target history. \(\boldsymbol{\rho}_{i_k,t}\) denotes the evidence-relation role of that historical interaction with respect to the target question, and \(\delta_{i_k,t}\) denotes its historical position information. Thus, \(G_{u,t}\) describes overall learning trends and risk, while local evidence blocks retain the specific support source of each interaction for the current prediction.

The global student state also contains recent response accuracy, recent error patterns, changes in pre-target performance, risk-level features and the distribution of major evidence roles. These aggregate features summarize the student's state near the prediction time and the source composition of the retrieved evidence.

Risk-level information is determined jointly by response outcomes on relevant evidence, question difficulty and support relations between evidence and target. Errors on related historical questions or unstable performance on prerequisite support questions indicate higher prediction risk, while correct performance over multiple evidence classes indicates stronger positive support. The role distribution records whether the evidence set is dominated by homogeneous transfer, semantic neighbors, prerequisite support, higher-order transfer or other relation sources.

\subsubsection{Local Transfer Evidence Blocks}

Local evidence blocks retain fine-grained information for each retrieved evidence item. For each \(e_{u,t}^{k}\) in \(E_{u,t}\), we construct a local evidence block \(B_{u,t}^{k}\) that contains the historical question representation, historical response outcome, evidence relation, support strength, historical position and role annotation with respect to the target question. Text semantics, hierarchical semantic identifier, cognition-enhanced semantics, collaborative representation and graph-structural relation describe the historical question's position in the multi-source relation space. The response outcome determines support direction, the evidence role specifies the relation to the target, and the support score and historical position record evidence value and temporal location.

The block records the evidence relation between the historical interaction and the target question, including prerequisite support, homogeneous transfer, semantic neighbor, higher-order transfer, graph-structural complement and collaborative complement. This role information allows the prediction module to distinguish the meanings of different evidence items rather than treating all historical questions as homogeneous inputs.

Through local evidence blocks, retrieved results are converted into a structured evidence sequence:
\[
B_{u,t}=\{B_{u,t}^{1},B_{u,t}^{2},\ldots,B_{u,t}^{K}\}
\]

Each element in this sequence corresponds to one target-conditioned evidence item and contains its question attributes, response state, evidence role and support information.

Here, structured evidence refers to the non-summary representation produced by retrieval and evidence-context construction. It includes retrieved evidence items, evidence roles, support scores, relation sources, historical positions, local evidence blocks, the global student state and evidence-structure features. These elements describe how each historical interaction supports the target before any schema-constrained summary is generated.

\subsubsection{Structured Evidence Summary}

Beyond the global state and local evidence blocks, we introduce a structured evidence summary to compress retrieved evidence under the target condition. This step uses a frozen LLM to read the target question, the student's recent statistical summary and the selected target-conditioned evidence. Its output is restricted to constrained summary fields: stable mastered points, persistent weak points, transfer state, risk level, evidence quality and a brief evidence description.

Formally, the structured evidence summary is denoted as
\[
D^{\mathrm{sum}}_{u,t}=\{\mathcal M_{u,t},\mathcal W_{u,t},\tau_{u,t},r_{u,t},\eta_{u,t},d_{u,t}\},
\]
where \(\mathcal M_{u,t}\) and \(\mathcal W_{u,t}\) denote evidence-supported mastered points and weak points, \(\tau_{u,t}\) denotes transfer state, \(r_{u,t}\) denotes risk level, \(\eta_{u,t}\) denotes evidence quality, and \(d_{u,t}\) denotes a brief evidence description.

This summary serves as an evidence-compression signal rather than a final-label predictor or an open-ended explanation. The summary description is encoded as a context vector, and the structured fields are converted into explicit features that enter the student-side context input.

For reproducibility, the structured evidence summary is implemented as a schema-constrained evidence compressor rather than an open-ended text generation module. The summarizer input contains only observable target-question information, the target concept set, the student's pre-target recent statistical summary, and the evidence IDs, roles, support strengths, historical response outcomes and question texts in the selected evidence set \(E_{u,t}\). The input does not contain the current target response label.

The output is restricted to a single JSON object with six top-level fields: \texttt{mastered\_concepts}, \texttt{weak\_concepts}, \texttt{transfer\_state}, \texttt{risk\_level}, \texttt{evidence\_quality} and \texttt{diagnosis}. The mastered-concept and weak-concept fields contain at most three entries each, consisting of a concept name, a set of evidence IDs and a confidence level. Risk level, evidence quality and confidence use the discrete levels low, medium and high.

The implementation constrains decoding with a JSON-only system prompt, an explicit user prompt, \texttt{response\_format=json\_object}, temperature 0.0 and a maximum output length of 256 tokens. Parsing failures or invalid fields trigger at most three retries, and summaries that remain invalid are not passed to subsequent encoding.

During encoding, a valid summary is rewritten into short text channels for stable mastery, weak risk, diagnostic statement and auxiliary state, and is combined with the target-conditioned context to form a summary-side embedding. The summary fields are also converted into fixed-dimensional structural features, including mastered-concept count, weak-concept count, mastered and weak indicators, normalized diagnosis length, risk-level one-hot features and evidence-quality one-hot features.

The summary embedding and summary-derived structural features enter the context projector as part of the student-side context features. The structured evidence summary is therefore a verifiable intermediate representation, rather than a free-text explanation that requires post hoc parsing.

\subsubsection{Context Representation for the Frozen Predictor}

The evidence context is finally converted into structured features for the soft-slot probability prediction module. We separate the representation into a student-side evidence context and a target-side representation. The student-side evidence context consists of the global student state, local evidence blocks, structured evidence summary, evidence-structure features and numerical state features. Evidence-structure features record major evidence roles, evidence count, support-score distribution and coverage over relation sources, while summary-derived features encode mastered concepts, weak concepts, transfer state, risk level and evidence quality.

The student-side evidence-context embedding integrates the global state and local evidence blocks, while absorbing compressed information from the structured evidence summary. It incorporates historical questions, response outcomes, evidence roles and support strengths in the retrieved evidence, forming a target-conditioned student-state representation. Numerical state features describe recent performance, risk level and dynamic trends.

The target-side representation describes the current prediction object through question text semantics, hierarchical semantic identifier, cognition-enhanced semantics, fitting-boundary collaborative vector when available, and related cognitive attributes. A collaborative vector is used only when the question has a fitting-boundary group-behavior representation; otherwise this component is zero-filled and contributes no response-derived target signal.

Together, the two representations keep the prediction condition explicit: the target-side prior specifies the question-side requirement, whereas the student-side context records the evidence state available before the response. This separation is preserved in the two projector inputs rather than collapsed into a single prompt.

The evidence-context construction module outputs
\[
X_{u,t}=(x^{ctx}_{u,t},x^{tar}_{t})
\]

where \(x^{ctx}_{u,t}\) denotes the student-side evidence-context features, and \(x^{tar}_{t}\) denotes the target-side multi-source prior features. This output organizes discrete retrieved evidence and summary-derived compression signals into a structured representation suitable for the prediction module.

The subsequent frozen-LLM soft-slot probability prediction module maps \(x^{ctx}_{u,t}\) and \(x^{tar}_{t}\) into context soft slots and target soft slots, respectively, and computes the probability that the student answers the target question correctly under label constraints.

This separation preserves the responsibility boundary of each information type: the target-side representation describes what the target requires, and the student-side context representation describes the student's evidence state under that target condition.

\subsection{Frozen-LLM Soft-Slot Probability Prediction}

\subsubsection{Constrained Representation Space of the Frozen LLM}

After evidence-context construction and structured evidence summary generation, the model obtains the student-side evidence-context features \(x^{ctx}_{u,t}\) and the target-side multi-source prior features \(x^{tar}_{t}\). The frozen-LLM soft-slot probability prediction module maps these two inputs to the correct-response probability estimate \(\hat{p}_{u,t}\) for an unseen-concept target.

We use the frozen LLM as a constrained conditional representation and label-discrimination space, not as a free generator or external knowledge source. The main LLM parameters are not trained. Training updates only the student-side context projector and target-side projector, which map structured evidence into the continuous input space of the LLM.

Let the parameters of the frozen LLM be \(\Theta\), which remain fixed during training. Let the student-side context projector be \(P_{\phi}^{ctx}\), and the target-side projector be \(P_{\psi}^{tar}\), where \(\phi\) and \(\psi\) are trainable parameters. For each prediction sample \((u,t,q_{u,t})\), the projectors map the student-side evidence context and target-side prior into continuous vector sequences:
\begin{align}
Z^{ctx}_{u,t} &= P_{\phi}^{ctx}(x^{ctx}_{u,t}), \\
Z^{tar}_{t} &= P_{\psi}^{tar}(x^{tar}_{t}).
\end{align}

Here, \(Z^{ctx}_{u,t}\) denotes context soft slots, and \(Z^{tar}_{t}\) denotes target soft slots. Context soft slots inject the student's evidence state under the current target condition, while target soft slots inject the multi-source prior of the current question.

With this design, the prediction module receives structured evidence without expanding the full history as text, and performs binary prediction in the representation space of the frozen LLM.

\subsubsection{Target-Conditioned Soft-Slot Injection}

Soft slots are intermediate representations between structured evidence features and the frozen LLM. They encode transfer evidence over seen concepts and the prior of the held-out target as continuous conditional inputs, preserving the structure produced by retrieval and context construction without rewriting the full history as prompt text.

Context soft slots come from the student-side evidence-context features \(x^{ctx}_{u,t}\). This component contains retrieved evidence, evidence roles, support strengths, recent state, risk level and summary-derived signals for mastered concepts, weak concepts, transfer state and evidence quality. The student-side projector \(P_{\phi}^{ctx}\) maps these heterogeneous features into a fixed-length continuous vector sequence. Because retrieval is target-conditioned, the context soft slots can differ across target questions for the same student.

Target soft slots come from the target-side multi-source prior features \(x^{tar}_{t}\). This component contains question text semantics, hierarchical semantic identifier, cognition-enhanced semantics, question attributes and only fitting-boundary collaborative relations when available. The target-side projector \(P_{\psi}^{tar}\) maps these priors into a continuous vector sequence. Target soft slots describe what the current question requires, and context soft slots describe the student's evidence state under that target condition.

The input organization retains both a textual prompt template and continuous soft slots. The prompt template states the KT task and candidate label constraints, while the soft slots carry the structured evidence used for prediction. Evidence selection is completed before LLM input construction.

The prompt template functions as a label-constrained task specification rather than a channel for target answers, external facts or full-history concatenation.

The conditional information fed into the frozen LLM consists of three parts: task prompt text, context soft slots and target soft slots. The overall input is denoted as
\[
I_{u,t}=[T;\,Z^{ctx}_{u,t};\,Z^{tar}_{t}]
\]

where \(T\) denotes the task instruction and label-constrained prompt, and \(Z^{ctx}_{u,t}\) and \(Z^{tar}_{t}\) denote the student-side and target-side continuous conditional inputs. This input structure jointly injects the KT task constraint, student evidence state and target-question prior into prediction.

\subsubsection{Label-Constrained Logit Probability Prediction}

We model KT over held-out concepts as binary probability estimation under an information boundary, rather than as a natural-language generation task. For input \(I_{u,t}\), the frozen LLM produces vocabulary logits at the candidate label position after the forward pass. The prediction module reads only the logits of the correct and incorrect labels, and uses softmax to obtain the probability that the student answers correctly. The LLM therefore performs conditional discrimination over encoded student evidence and target priors. The output contains no free text that must be parsed.

Here, \(p_{u,t}=P(y_{u,t}=1\mid H_{u,<t},q_{u,t},a(q_{u,t}))\) denotes the theoretical correct-response probability under the pre-target history and observable target-question prior, and \(\hat p_{u,t}\) denotes the model estimate. Let \(o^{+}_{u,t}\) and \(o^{-}_{u,t}\) denote the logits corresponding to the correct and incorrect labels. Then
\[
\hat p_{u,t}=f_{\Theta,\phi,\psi}(I_{u,t})=\frac{\exp(o^{+}_{u,t})}{\exp(o^{+}_{u,t})+\exp(o^{-}_{u,t})}.
\]

The corresponding model-estimated probability of an incorrect response under the same input \(I_{u,t}\) is
\[
1-\hat p_{u,t}=\frac{\exp(o^{-}_{u,t})}{\exp(o^{+}_{u,t}) + \exp(o^{-}_{u,t})}.
\]

This output form directly matches the probability scores required by KT evaluation. Our method uses label logits for binary probability computation, and \(\hat{p}_{u,t}\) is used to compute the training loss and to evaluate AUC, ACC, F1 and RMSE during testing.

During training, given the true label \(y_{u,t} \in \{0,1\}\), we optimize the projector parameters with binary cross-entropy loss:

\[
\mathcal{L} = -\sum_{(u,t)} \left[
    y_{u,t} \log \hat{p}_{u,t}
    + (1-y_{u,t}) \log(1-\hat{p}_{u,t})
\right]
\]

Under this objective, the frozen LLM parameters \(\Theta\) are not updated. The optimization targets are the student-side context projector parameters \(\phi\) and the target-side projector parameters \(\psi\). Training maps student-side evidence context over seen concepts and multi-source priors of unseen targets into a continuous input space suitable for label discrimination.

Because the main LLM remains frozen, task adaptation occurs in the mapping layer from evidence to soft slots. The model relies on transferable conditional representations rather than concept-specific memory for held-out concepts in updated LLM parameters.

The soft slots are projected from evidence features and serve binary label-logit prediction\citep{lester2021power,li2021prefixtuning}. This process preserves the temporal constraints and probabilistic output form of KT through a compact evidence interface.

\subsubsection{Unseen-Concept Knowledge Tracing Evaluation Protocol}

Cold start in KT is not limited to new students or new questions. It can also occur when knowledge concepts have not appeared during training. We treat such cases as an unseen-concept knowledge tracing setting rather than redefining them as a separate task. Each test target is associated with at least one concept absent from training supervision, so the model cannot rely only on experience from existing concept or question IDs. This setting evaluates whether the model can combine prior learning history with available target-question priors and transfer learned representations to held-out concepts.

Specifically, we construct the evaluation split by holding out a subset of concepts from supervised training. Let \(\mathcal{C}_{\mathrm{u}}\) denote the held-out concept set. A target question is included in the test set if its associated concept set overlaps with \(\mathcal{C}_{\mathrm{u}}\), namely \[C(q_{u,t})\cap\mathcal{C}_{\mathrm{u}}\neq\emptyset .\] This construction reflects the multi-concept nature of educational questions: a target may involve both previously observed and held-out concept requirements, but every evaluated target contains at least one concept without training-stage supervision. The protocol therefore evaluates inductive prediction under held-out concept requirements at the target-question level.

During testing, the model uses only the student's historical interactions before the target question, together with the question text, concept information and static attributes available before the response. Difficulty, collaborative relations and graph-structural statistics that depend on response records are generated from training interactions and frozen during testing. For held-out target questions, the collaborative question vector is used only if it is available from this training boundary; otherwise the corresponding target-side component is zero-filled and no validation or test response records are used to construct it.

\subsubsection{Compared Models}

The main experiments compare existing KT baselines with the proposed method. Results are reported only for models evaluated on the same data splits and the same test samples. External baselines include representative models such as DKT~\citep{piech2015deep}, SAKT~\citep{pandey2019sakt}, SAINT~\citep{choi2020saint}, AKT~\citep{ghosh2020akt}, DIMKT~\citep{shen2022dimkt} and QIKT~\citep{chen2023qikt}.

The comparison also includes TCKT~\citep{huang2024tckt}, SimpleKT~\citep{liu2023simplekt}, SparseKT~\citep{huang2023sparsekt}, DenoiseKT~\citep{deng2025denoisekt}, RobustKT~\citep{guo2025robustkt} and KeenKT~\citep{li2026keenkt}. Model categories and input information are provided in Appendix Table~\ref{tab:appendix-comparison-models}.

Traditional KT baselines mainly predict from student historical interaction sequences and do not use the retrieved evidence constructed by Cognitive-RAG. Cognitive-RAG KT uses question-side multi-source priors and student-side evidence-context features. The latter contain retrieved evidence, structured evidence attributes and structured evidence summary-derived features. The model projects these multi-source signals into soft slots, feeds them into a frozen Qwen3-8B model\citep{yang2025qwen3,qwen2025qwen38b}, and reads label logits followed by a binary softmax to obtain \(\hat{p}_{u,t}\). It does not predict through free-text generation.

The comparison is designed as a paradigm-level evaluation under the same data split and test targets, rather than as an equal-input feature ablation across all models. Its focus is to evaluate how different modeling paradigms adapt to unseen-concept knowledge tracing. The interpretation of results is therefore scoped to whether combining retrieved evidence with the representation space of a frozen LLM improves KT probability prediction.

\subsubsection{Implementation Details}

The method sequentially performs target-conditioned evidence retrieval, evidence-context construction, structured evidence summary generation, soft-slot feature transformation and probability prediction. Candidate evidence is recalled through knowledge, semantic, collaborative and graph-structural relations of the target question, and is reranked with relevance, coverage and redundancy control. The structured evidence summary compresses retrieved evidence into fields such as mastered concepts, weak concepts, transfer state, risk level and evidence quality, and enters the projector as part of the student-side context features.

The prediction module uses a frozen Qwen3-8B and trains only the student-side and target-side projectors. The main experiments use both context soft slots and target soft slots, and compute \(\hat{p}_{u,t}\) through a binary softmax over label logits\citep{yang2025qwen3,qwen2025qwen38b,qwen2025qwen3embedding,qwen2025qwen3reranker}. Appendix Table~\ref{tab:appendix-main-method-config} gives the complete retrieval settings, structured evidence summary schema, soft-slot prediction configuration and training configuration.

Their bootstrap 95\% confidence intervals are [0.8393, 0.8416], [0.7525, 0.7559] and [0.7793, 0.7816], indicating stable probability-ranking performance over large-scale unseen-concept test samples.

Figure~\ref{fig:paired-bootstrap-deltas} further reports paired bootstrap differences between the proposed method and DenoiseKT, the strongest baseline on each dataset. The differences in AUC, ACC and F1, and the reductions in RMSE, are positive on all three datasets. The corresponding 95\% confidence intervals do not cross zero. These results indicate that, on the same unseen-concept test targets, Cognitive-RAG KT achieves higher point estimates than the strong sequential baseline and shows a statistically stable relative advantage.

The gain pattern differs across datasets. The AUC gain is largest on FoundationalASSIST. On XES3G5M, both AUC and threshold-based metrics improve steadily. On MOOCRadar, although the positive-class ratio is high, the proposed method maintains clear advantages in AUC and RMSE. Across the three datasets, the gain should not be interpreted simply as an effect of adding more input information. It is better understood as an improvement in conditional discrimination over held-out concept targets after question-side priors and student pre-target histories are organized as structured evidence for the current prediction.

\subsection{Ablation Design and Analysis}

The ablation experiments focus on three key components that can be directly mapped to the current results: target-conditioned evidence retrieval, structured evidence summary and structured evidence. Target-conditioned evidence retrieval decides which pre-target interactions enter \(E_{u,t}\). Structured evidence denotes the non-summary evidence representation attached to those interactions, including evidence roles, support scores, relation sources, historical positions, local evidence blocks, global student-state features and evidence-structure features. Structured evidence summary denotes the schema-constrained compressed fields derived from the selected evidence, including mastered concepts, weak concepts, transfer state, risk level and evidence quality. The full model retains all three components. Each variant removes only the component indicated by its name, while keeping the remaining input and prediction pipeline unchanged.

All variants run on the same fixed label-stratified evaluation manifest, so that component differences are compared under a controlled test-target set. The manifest uses the \texttt{sample\_id} corresponding to the triplet \((u,t,q_{u,t})\) to align the student, target time step, target question and test label. It is used only to fix evaluation samples and compute metrics, and it does not participate in evidence generation or probability prediction. Variant definitions and the shared evaluation protocol are given in Appendix Table~\ref{tab:appendix-ablation-design}. Thus, the Remove structured evidence summary variant removes only the summary embedding and summary-derived structural features from the predictor, while retaining the selected evidence items and their non-summary structured attributes. The Remove structured evidence variant removes the non-summary role, support, relation and evidence-structure attributes from the predictor; target-conditioned retrieval and the structured evidence summary remain retained in that variant as specified in Table~\ref{tab:appendix-ablation-design}.

The structured evidence summary functions as auxiliary compression of retrieved evidence. Since some threshold-based metrics and error metrics show different directions in a few variants, the ablation conclusion is scoped to probability-ranking performance: target-conditioned evidence retrieval is the most stable contributor to AUC, structured evidence provides secondary support, and structured evidence summaries provide a smaller complementary gain. Component effects on threshold-based metrics are treated as diagnostic rather than uniformly positive.

For controlled and reproducible component analysis, we compare key components on a fixed test-target subset shared by all ablation variants. This setting keeps the training data and test target set consistent while supporting repeated evidence construction, retrieval and frozen-LLM inference across component variants. The main experiments are still reported on the full test sets, while the ablation experiments analyze the relative contribution of different components.

\section{Conclusion}

We propose Cognitive-RAG KT for knowledge tracing over concepts unseen during training. The core idea is not to expand the amount of historical input. Instead, the model selects transferable evidence from a student's pre-target history conditioned on the target question, maps the evidence context, structured evidence summary-derived features and target-side prior into soft slots, injects them into a frozen LLM, and outputs the probability of a correct response from label logits.

Experiments show that Cognitive-RAG KT outperforms multiple KT baselines under unseen-concept evaluation. Pure unseen-concept slice analysis provides a diagnostic view of performance on stricter held-out concept targets. Key-component ablations further show that target-conditioned evidence retrieval is the most stable source of contribution, structured evidence provides secondary support, and structured evidence summaries provide auxiliary compressed information. The main conclusion is that, for KT over concepts unseen during training, explicitly selecting and organizing transferable evidence from the student's pre-target history provides more effective information for the frozen LLM's probability discrimination than target-agnostic compression of historical sequences.

\section{Limitations and Future Work}

Cognitive-RAG KT achieves stable overall improvements on three public datasets, and several extensions can further strengthen evidence validation. First, the current experiments support the effectiveness of target-conditioned evidence retrieval through overall comparison, slice analysis, stratified analysis and component ablation under offline predictive evaluation. Future work can more directly characterize the credibility of retrieved evidence through evidence masking, counterfactual evidence replacement, retrieval perturbation, expert evaluation and evidence-consistency analysis. These tests can examine whether the historical interactions used by the model genuinely support the current prediction, rather than reflecting surface correlations from question similarity, concept frequency or dataset bias.

Second, the structured evidence summary is designed as a constrained compression of retrieved evidence rather than as an independently validated cognitive diagnosis. We use it as student-side context features and summary-derived features, and evaluate its predictive contribution through ablation. Future work can examine whether the summary fields align with teacher judgments, student error causes or future learning gains through manual annotation, expert evaluation or intervention studies.

Third, we study correct-response probability prediction under pre-target history and evaluate it with offline metrics such as AUC, ACC, F1, RMSE and BCE. This setting establishes offline predictive validity, while instructional intervention requires additional online deployment, teacher-facing evaluation and learning-gain analysis.

Future work should further examine probability calibration, stability on low-frequency concepts and new-student scenarios, and the relation between model outputs and learning gains, error-cause diagnosis and personalized intervention. For LLM-based KT methods, offline prediction improvement should be complemented by evidence validation, including whether the evidence used and presented by the model is verifiable, traceable and useful to teachers.

Fourth, the frozen LLM improves the conditional representation and probability discrimination capability of the structured evidence context, and it introduces a deployment trade-off in inference cost. Future work can explore evidence caching, soft-slot distillation, lightweight student-model substitution, retrieval-candidate precomputation and joint retriever-predictor compression for large-scale online learning platforms.

Future work can also systematically analyze the performance-cost trade-off among retrieval scale, slot count, LLM parameter size and inference latency. This analysis can support deployment settings that preserve prediction performance and evidence credibility while reducing inference cost.

\subsection{Key-Component Ablation Protocol}

Table~\ref{tab:appendix-ablation-design} defines the variants in Table~\ref{tab:ablation_study}. All variants share the same training data, the same random seed and the same fixed label-stratified test target subset. Paired bootstrap analysis is performed on 50,000 target samples for each dataset. The main experiments are reported on the full test sets, so the full-model row in the ablation table is a within-protocol reference and is used only for relative component comparison under the fixed-subset protocol.

The fixed test target subset is exported from the main-experiment test prediction file as an evaluation manifest. The entry point is \texttt{scripts/build\_llm\_ablation\_eval\_manifest.py}. Each line in the manifest uses the \texttt{sample\_id} corresponding to \((u,t,q_{u,t})\) as the unique key, and records the dataset name, test split, student ID, target time step, target question ID and true label.

If a sampling size is specified, the manifest uses label-stratified random sampling with default random seed 42. If the sampling size is 0, all test rows are retained. After generation, the metadata records the source prediction file, source test sample count, selected sample count, sampling strategy, random seed, positive and negative label counts, and manifest SHA-256.

Subsequent ablation runs read this fixed manifest through \texttt{scripts/run\_llm\_ablation\_experiments.py} without new \texttt{sample\_size}, \texttt{max\_samples} or offset parameters. The run configuration records \texttt{eval\_manifest\_jsonl}, variant names, loaded sample count and selected label distribution, and checks that manifest labels are consistent with target labels in the student data. This protocol supports component-level comparison in Table~\ref{tab:ablation_study} under unchanged test targets and label composition.

This distinction separates the effect of retaining structured metadata on retrieved interactions from the effect of adding the compressed summary representation.
